# Reproduction scripts

One script per table / figure / reported number of the manuscript
*"Connection Order Matters: Path-Dependent Hosting Capacity in Distributed
Generation Interconnection Queues"* (Results in Engineering, revised version).

All scripts resolve paths relative to the repository root — they run from any
clean checkout. Raw per-run campaign data lives in `../analysis-output/`
(JSON, one record per run, algorithm seeds included). The frozen experiment
code is `../execution/`.

## Setup

```bash
pip install -r ../requirements.txt   # pandapower>=3.4, numpy, scipy, matplotlib
```

## Statistical tables (seconds each — recompute from the raw JSONs)

| Script | Reproduces | Data |
|---|---|---|
| `reproduce_gain_ci.py` | MA-vs-FIFO gain table (bootstrap 95% CIs, seed 12345) and the +29.8% / +4.9% aggregates | `experiment_optionA_*.json`, `results_69bus_saved.json` |
| `reproduce_ablation.py` | MA vs GA-only ablation (paired Wilcoxon, Cohen's d, 9 configurations) | `ablation_multiseed_*.json` |
| `reproduce_fairness.py` | Fairness table (D_max costs, Bonferroni-corrected tests, d ranges) | `fairness_multiseed_*.json` |

Each of these carries the published values hardcoded and prints a match flag
per row, so they double as reproduction gates.

## Experiment replays (re-run the physics)

| Script | Reproduces | Cost |
|---|---|---|
| `rejection_breakdown_all.py` | Binding-constraint appendix (100% overvoltage; max loss 8.6%) on all 12 restrictive instances | ~1 min |
| `limiar_ativacao.py` | Activation-threshold binary search (33-bus 160–200%, 69-bus 216–311%) | ~3 min |
| `baseline_estatico.py` | Static multicriteria (TOPSIS proxy) baseline table | ~1 min |
| `bfs_crosscheck.py` | BFS-vs-NR cross-validation (max dV = 3.3e-3 pu, base 33-bus) — uses the self-contained `bfs_standalone.py` | seconds |
| `trivial_69bus.py` | Deterministic orderings on the trivial 69-bus I1/I2 instances (all 50 projects connect with identical totals — Statistical Protocol section) | ~1 min |
| `robustness_mc.py` | Paired Monte Carlo robustness table + figure (recovers optimal permutations from recorded seeds; hard reproduction gate before sampling) | ~2–3 h |
| `enum_n8.py --full` | Reduced-scale exhaustive enumeration (certified global optimum, 6 × 8! evaluations; MA/GA reach it in 60/60 runs each) | ~10 h |
| `sensibilidade.py --full` | OFAT sensitivity (population, generations, V_max; 12 cells) | ~17 h |

`enum_n8.py` and `sensibilidade.py` accept `--smoke` (cost estimate) and
single-cell arguments; both write incrementally, so interrupted runs resume.
Reference outputs of every replay are committed in `../analysis-output/`
(`enum_n8_resultados.json`, `sensibilidade_resultados.json`,
`limiar_ativacao_resultados.json`, `baseline_estatico_resultados.json`,
`robustness_mc_results.json`, `trivial_69bus_deterministic.json`).

The Markdown files in `../analysis-output/` are dated working notes from the
April campaign; where their aggregation differs from the manuscript (each
carries a note at the top), the manuscript and these scripts are
authoritative.

## Figures

The manuscript figures are generated by `../execution/generate_figures.py`,
`../execution/generate_figures_ablations.py` and
`../execution/generate_figures_ieee.py` (from the same campaign JSONs; see
`../analysis-output/figure-catalog.md` for the figure–data mapping). The
robustness figure is produced by `robustness_mc.py` in this folder.

## Determinism

The memetic algorithm is deterministic given `MAConfig.seed`
(`np.random.default_rng`); campaign run seeds follow
`run_seed = instance_seed * 1000 + run_index` and are recorded per run in the
JSONs. Instance seeds: 42, 7, 13. See Appendix "Synthetic Queue Generation
Procedure" of the manuscript for the queue-generation contract.
